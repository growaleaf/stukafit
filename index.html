What this counts

"Core functions" are counted from a dated primary source per aircraft class — not the game's full bindable-key list. IL-2 Sturmovik: Great Battles does not publish its own consolidated per-aircraft control-count reference, so the counts here come from a public, community-maintained reference spreadsheet that maps every default key-mapping-menu entry against every aircraft in the game. A function counts if it carries a real default keybind in that sheet and a marker showing it applies to the representative aircraft for that class. "Slots" means physical buttons, axes, and hats on the controller, counted from the manufacturer's own product page. One physical input covers one function.

This tool reports counts. It does not tell you a controller is required, sufficient, or the best choice for IL-2 — that judgment is yours.

Controllers and aircraft classes covered

Controllers: Thrustmaster T.16000M FCS, T.16000M FCS HOTAS, T.Flight HOTAS X, Logitech G X56 H.O.T.A.S.

Aircraft classes: Single-Engine Fighter (represented by the Bf 109 G-6), Multi-Engine Bomber (represented by the He 111 H-6). The bomber class carries far more core functions — independent throttle/mixture/prop/radiator controls per engine, plus bomb sight, bomb bay, and gunner/turret station switching that a fighter never uses.
